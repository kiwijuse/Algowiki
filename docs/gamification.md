# 게임화 시스템 설계

AlgoWiki가 기존 PS 사이트와 어떻게 다른지 전부 여기에 적었습니다.

---

## 설계 원칙

1. **보상은 문제를 푸는 행동에서만 나온다.** 재화를 사는 경로는 없다.
2. **재화를 쓸 곳이 항상 있어야 한다.** 쌓이기만 하면 의미가 죽는다.
3. **얻은 것은 남에게 보여야 한다.** 프로필 테두리·닉네임 색은 전역에 노출된다.
4. **막힌 사람을 놓아주지 않는다.** 힌트·시간복잡도 확인권은 이탈 방지 장치다.

---

## 1. 퀘스트

네 종류로 나눴습니다.

| 종류 | 초기화 | 성격 |
|---|---|---|
| **일일 퀘스트** | 매일 | 매일 올 이유를 만드는 짧은 목표 |
| **주간 퀘스트** | 매주 | 누적형 · 보상이 큼 |
| **메인 퀘스트** | 없음 (영구) | 계정 성장의 큰 줄기 |
| **히든 퀘스트** | 없음 (영구) | 달성 전까지 제목·내용이 `???` |

### 대표 퀘스트

| 퀘스트 | 조건 | EXP | 코인 |
|---|---|---:|---:|
| **Random - Tag** | 매일 무작위 배정된 **태그**의 문제 1개 해결 | 150 | 15 |
| **출석 체크** | 아무 문제나 1개 해결 | 50 | 5 |
| **Random - Beginner** | 지목된 Beginner 난이도 문제 해결 | 50 | 5 |
| **Random - Normal** | 지목된 Normal 난이도 문제 해결 | 75 | 7 |
| **Random - Advanced** | 지목된 Advanced 난이도 문제 해결 | 100 | 10 |
| **산뜻한 출발** | 퀴즈 1개 풀기 | 20 | 2 |
| **알찬 한 주** | 주간 누적 풀이 | — | — |
| **꾸준함** | 7일 연속 출석 (출석 체크와 연동 상승) | — | — |

### 랜덤 퀘스트

매일 자정에 사용자마다 문제를 새로 지목합니다.
이때 **이미 푼 문제는 후보에서 빼야** 합니다.
안 그러면 어제 푼 문제가 다시 나와서 퀘스트가 공짜가 되어버립니다.

태그 퀘스트도 매일 태그를 갈아끼웁니다 — 그날 배정된 태그의 문제를 풀어야만 진행됩니다.

### 목록 정렬

퀘스트 목록은 **진행률이 높은 순**으로 정렬됩니다.
거의 다 깬 퀘스트가 항상 맨 위로 올라와서 *"조금만 더 하면 되는데"* 가 눈에 띕니다.

### 보상 수령

진행도가 다 차도 자동으로 주지 않습니다. **직접 눌러야** 합니다.

누르는 순간 폭죽이 터지고 코인·EXP 카드가 갱신됩니다.
"받는 행동"은 의도적으로 남겨뒀습니다 — 성취를 확인하는 순간이 있어야 하기 때문입니다.

## 2. 성장 — 레벨과 티어

### 레벨

누적 경험치만 저장해두고 **레벨은 화면에 그릴 때 계산**하니
레벨 구간표가 바뀌어도 사용자 데이터를 건드릴 필요가 없습니다.

프로필 카드에는 현재 레벨과 **다음 레벨까지의 진행률(%)** 이 함께 뜨고
진행바에 마우스를 올리면 남은 EXP가 툴팁으로 나옵니다.

7개 티어 × Ⅰ·Ⅱ 두 단계 = **13단계**. 문제 카드와 문제 페이지에 색과 보석 아이콘으로 표시됩니다.

난이도를 보여주는 방식은 사용자가 직접 고릅니다.

| 설정 | 왜 필요한가 |
|---|---|
| 표시 안 함 | 선입견 없이 풀고 싶은 사람 |
| 항상 표시 | 난이도 보고 고르고 싶은 사람 |
| **내가 푼 문제만** 표시 | 풀기 전엔 모르고, 푼 뒤에 확인하고 싶은 사람 |

세 번째가 실제로 가장 반응이 좋았습니다.
안 푼 문제는 `?` 로 가려지고 맞히는 순간 난이도가 공개됩니다.

티어 아이콘은 v1 → v2 → v3 세 번 다시 그렸습니다 (`assets/tier/`).

## 3. 재화와 상점

**알고 코인** 하나만 씁니다. 현금 결제 경로는 없습니다.

<img src="../assets/screenshots/userinfo_shop.png" width="380" align="right">

### 상점 구획

| 구획 | 갱신 | 내용 |
|---|---|---|
| **특가 상품** | 48시간 타이머 | 프로필 테두리 할인 |
| **데일리 상품** | 24시간 타이머 | 난이도별 힌트권 |
| **상시 상품** | 고정 | 리롤권 · 힌트권 · 복권 · 확인권 |
| **프로필 테두리** | 고정 | 36종 |

남은 시간을 카운트다운으로 보여주고 할인율 배지를 카드 모서리에 얹었습니다.
"지금 아니면 사라진다"는 압박을 만들되 **재화를 살 수 없으니** 결국 문제를 풀게 됩니다.

<br clear="right">

### 아이템

| 아이템 | 효과 |
|---|---|
| **난이도별 힌트권** | 해당 난이도 이하 문제의 상세 힌트 해금 |
| **시간복잡도 확인권** | 문제의 *의도된* 시간복잡도 공개 |
| **Random 리롤권** (Beginner / Normal / Advanced) | 지목된 문제 다시 뽑기 |
| **Random - Tag 퀘스트 리롤** | 배정된 태그 다시 뽑기 |
| **일일퀘스트 리롤권** | 일일 퀘스트 세트 전체 재구성 |
| **닉네임 컬러 변경권** (1~4등급) | 등급별 색상 풀에서 무작위 획득 |
| **스트릭 컬러 변경권** | 잔디 그라데이션 색 무작위 획득 |
| **알고 복권 · 럭키 박스** | 확률형 |
| **프로필 테두리** | 36종 중 지정 구매 |

리롤권을 넣은 이유는 단순합니다. 오늘 지목된 문제가 도저히 안 풀릴 때
**하루를 통째로 날리는 대신 다른 문제로 갈아탈 수 있어야** 하기 때문입니다.

## 5. 힌트 — 이탈 방지 장치

게임화의 목적은 재미만이 아니라 **완주율**이라
막힌 사람이 그냥 창을 닫는 걸 막아야 합니다.

문제 페이지는 힌트를 두 겹으로 나눕니다.

1. **기본 힌트** — 누구나 볼 수 있는 방향 제시
2. **아이템 힌트** — 힌트권으로 해금. 언어별 코드 골격까지 제공

<img src="../assets/screenshots/problem.png" width="620">

시간복잡도 확인권은 별도입니다.
"이 문제는 O(N log N)으로 풀어야 한다"만 알아도 접근이 확 달라지는 경우가 많아
**답을 주지 않으면서 방향만 주는** 아이템으로 따로 분리했습니다.
