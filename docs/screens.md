## 명예의 전당

<img src="../assets/screenshots/problem_rank.png">

문제마다 네 개 부문의 시상대를 세웠습니다.

| 부문 | 기준 |
|---|---|
| **속도** | 실행 시간이 가장 짧은 제출 |
| **메모리** | 메모리 사용량이 가장 적은 제출 |
| **숏코딩** | 코드 길이가 가장 짧은 제출 |
| **선발대** | 가장 먼저 정답을 낸 제출 |

정답을 맞히는 것 말고도 **경쟁할 축**을 여러 개 두어 이미 푼 문제로 다시 돌아올 이유를 만들었습니다.

## 퀘스트

<img src="../assets/screenshots/userinfo_quest.png">

- 상단에서 **일일 / 주간 / 메인** 전환
- 진행바가 `0/6` 처럼 분류별 클리어 수를 표시
- 각 퀘스트 카드: 육각형 아이콘 · 제목 · 조건 · 진행도 · EXP · 코인
- 조건 안의 태그명(`쿼리형 문제`)과 문제 번호(`1006`)는 **바로 그 목록/문제로 가는 링크**
- 완료된 퀘스트에는 **보상 수령** 버튼이 붙고, 누르면 폭죽이 터지며 좌측 프로필이 갱신됩니다
- 히든 퀘스트는 달성 전까지 제목·내용이 `???`

좌측 프로필 카드에 프로필 테두리 · 닉네임 색 · 칭호 · LV · EXP 바 · 코인이 한눈에 들어옵니다.

## 설정

<img src="../assets/screenshots/userinfo_setting.png">

좌측 사이드바로 두 그룹을 나눴습니다.

| **내 정보** | **설정** |
|---|---|
| 비밀 번호 변경 | 표시 (난이도 · 태그 노출 방식) |
| 이메일 주소 변경 | 공개 (소스 · GitHub · Discord · Blog 개별 토글) |
| 한줄 소개 변경 | 프로필 테두리 변경 |
| 연결 정보 관리 | 칭호 변경 |
| 회원 탈퇴 | |

비밀번호는 입력 즉시 **"비밀번호가 일치합니다"** 를 인라인으로 검증합니다.
각 항목은 `setting_ajax.php` 가 폼 조각을 내려주고 저장은 `php_ajax.php` 가 받습니다.
